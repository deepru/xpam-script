# XPAM Script v1.5.0

Выпуск совместимости с обновлёнными 3x-ui и Xray. WARP учитывает изменения настроек ядра,
а при недоступности регистрации можно импортировать отдельный аккаунт через меню XPAM.

## Изменения

- **Импорт аккаунта WARP.** Новый пункт «Импортировать аккаунт и включить WARP» принимает полный
  ответ регистрации 3x-ui. XPAM проверяет настоящий туннель до включения маршрутов; при неудачной
  настройке восстанавливает прежние настройки WARP. Порядок переноса описан в
  [руководстве](https://github.com/deepru/xpam-script/blob/main/docs/USER_GUIDE_RU.md#ch15).
- **WARP на новом Xray.** XPAM выбирает IPv4-параметры под установленное ядро и сохраняет
  выбранный режим WireGuard. Обновление XPAM выполняется перед обновлением панели и ядра.
- **OCSP без повторяющихся предупреждений.** Восстановление убирает лишний запрос OCSP у основного
  сертификата, если сертификат его не поддерживает.
- **Клиенты сохраняются при отключении подключений.** Удаление запасного транспорта или
  Telegram proxy / MTG сохраняет клиента, если он используется другим подключением панели.
  При неудачном переключении запасного транспорта возвращается прежняя конфигурация.
- **Надёжнее резервирование и откат.** Резервная копия учитывает записи в работающей SQLite.
  Обновление проверяет все ссылки подключения и замечает прерванную диагностику.
  Ошибка проверки здоровья больше не отображается как успех.
- **Короткая проверка портов.** Закрытые UFW исходящие UDP-сокеты Xray показаны одной сводкой;
  потенциально доступные извне порты по-прежнему видны отдельно.
- **Пользовательские скрипты маршрутизации.** При таком скрипте автоматическое изменение WARP
  или DoubleHop Mode останавливается с пояснением. Согласуйте маршрутизацию перед повторной настройкой.
- **Меньше лишних предупреждений XHTTP.** Запасной транспорт очищает недостоверные заголовки
  адреса клиента, передаваемые через локальный TLS-маршрутизатор.

## Установка

```bash
cd /root
curl -fsSL https://raw.githubusercontent.com/deepru/xpam-script/main/bootstrap.sh -o xpam-bootstrap.sh
sudo XPAM_REPO="deepru/xpam-script" bash xpam-bootstrap.sh
```

Требования и порядок установки — в
[руководстве пользователя](https://github.com/deepru/xpam-script/blob/main/docs/USER_GUIDE_RU.md).
Bootstrap проверяет контрольную сумму архива перед запуском установщика.

Проверить скачанный архив самостоятельно:

```bash
sha256sum -c xpam-script-v1.5.0.tar.gz.sha256
```

## Обновление с v1.4.2

1. `sudo <prefix>-xpam` → «Дополнительно / обслуживание» → «Проверить обновления XPAM».
2. XPAM скачает архив, сверит контрольную сумму, создаст резервную копию и проверит результат.
   Если обновление добавит проблему, выполнится откат.
3. Выполните `sudo <prefix>-health --deep`.

Ссылки подключения, домены, клиенты, настройки DoubleHop Mode и WARP сохраняются.

## Секреты

Не публикуйте вывод `sudo <prefix>-links`. Для публичной диагностики используйте
`sudo <prefix>-links --safe`; правила обращения с секретами — в
[SECURITY.md](https://github.com/deepru/xpam-script/blob/main/SECURITY.md).
