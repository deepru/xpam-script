# XPAM Script v1.5.1

Регистрация WARP при недоступном API Cloudflare: XPAM может временно использовать другой
VLESS-сервер, а после операции вернуть прежний выход панели.

## Изменения

- **Временный VLESS-выход для регистрации.** XPAM сначала пробует обычную регистрацию.
  При ошибке доступа к API Cloudflare предлагает ввести VLESS-ссылку. Если DoubleHop Mode
  включён, можно использовать его сохранённую ссылку или ввести другую. Состояние
  DoubleHop Mode и клиентские маршруты сохраняются.
- **Регистрация без включения маршрутов.** Новый пункт «Зарегистрировать аккаунт WARP
  без включения маршрутов» сохраняет аккаунт для последующей настройки. Повторное
  обращение к API для получения уже сохранённых данных подключения не требуется.
- **Очистка временного выхода.** После успеха, ошибки или отмены XPAM возвращает прежний
  выход панели и удаляет временные данные VLESS. Сохранённая ссылка действующего
  DoubleHop Mode остаётся. Предусмотрено восстановление после аварийного прерывания.

Доступность самого WARP-туннеля проверяется отдельно перед включением маршрутов.
Порядок действий — в [руководстве](https://github.com/deepru/xpam-script/blob/main/docs/USER_GUIDE_RU.md#ch15).

## Установка

```bash
cd /root
curl -fsSL https://raw.githubusercontent.com/deepru/xpam-script/main/bootstrap.sh -o xpam-bootstrap.sh
sudo XPAM_REPO="deepru/xpam-script" bash xpam-bootstrap.sh
```

Требования — в [руководстве пользователя](https://github.com/deepru/xpam-script/blob/main/docs/USER_GUIDE_RU.md).
Bootstrap сверяет контрольную сумму архива перед запуском установщика.

```bash
sha256sum -c xpam-script-v1.5.1.tar.gz.sha256
```

## Обновление с v1.5.0

1. `sudo <prefix>-xpam` → «Дополнительно / обслуживание» → «Проверить обновления XPAM».
2. XPAM проверит архив, создаст резервную копию и проверит результат обновления.
3. Выполните `sudo <prefix>-health --deep`.

## Секреты

Не публикуйте вывод `sudo <prefix>-links`. Для публичной диагностики используйте
`sudo <prefix>-links --safe`; правила обращения с секретами — в
[SECURITY.md](https://github.com/deepru/xpam-script/blob/main/SECURITY.md).
